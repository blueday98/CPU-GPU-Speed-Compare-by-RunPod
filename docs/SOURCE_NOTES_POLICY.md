# 원본 학습 노트 처리 방침

이 저장소의 문서는 사용자가 작성한 네 개의 RunPod 분석 노트와 실제 코드·JSON 증거를 교차 검토해 작성했다.

원본 PDF 자체는 공개 저장소에 포함하지 않는다.

- 내부 Job ID와 Object Storage 객체명이 포함됨
- 당시에는 맞았지만 후속 배포로 무효가 된 경로가 섞여 있음
- 같은 수치가 서로 다른 측정 범위로 반복됨
- 인증 토큰을 다룬 명령이 포함됨
- 최신 코드와 다른 파일명·단계 구성이 포함됨

대신 의미 있는 실험 과정, 명령의 목적, 수치, 실패와 정정 사항을 `PROJECT_HISTORY.md`에 시간순으로 보존했다. 비밀정보와 개인 식별 정보는 제거한다.
