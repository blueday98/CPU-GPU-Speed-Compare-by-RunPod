# 조장 확인 목록

## 확인할 것

- 최신 운영 작업 처리기 코드와 배포 이미지
- 기존 GPU 분기가 공식 배포에서 제거된 것이 의도된 변경인지
- GPU 경로를 최신 코드에 정식으로 합칠 담당자와 검토 방식
- CPU와 GPU 결과 차이의 허용 기준

## 물어볼 말

> 운영 서비스를 수정하지 않고 같은 영상으로 격리 시험했습니다. RunPod GPU 전체 왕복시간이 기존 OCI CPU보다 60fps 영상은 48.01%, 29.97fps 영상은 79.05% 짧았습니다. RunPod 비용은 제가 부담합니다. 이 GPU 경로를 최신 작업 처리기 코드에 정식으로 반영해 사이트와 Grafana에서 검증해도 될까요?

## 설명할 핵심

- GPU 시간은 OCI 업로드부터 RunPod 처리와 결과 다운로드까지 포함한다.
- 특징값 계산과 코칭 리포트 생성은 비교 범위 밖이다.
- Runner's Feed 운영 작업 처리기, DB, Grafana는 변경하지 않았다.
- 60fps 결과는 매우 유사했지만, 29.97fps 영상의 349번 프레임에서 CPU와 GPU의 인원 수가 달랐다.
- 정식 적용은 임시 덮어쓰기가 아니라 검토 가능한 코드 변경과 공식 배포로 진행해야 한다.
